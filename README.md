# SpeakFlow English Coach

Monte a interface completa e funcional do SpeakFlow English — Fase 1: Conversação conforme as especificações detalhadas:

1. Objetivo & Identidade:
- Aplicação web SpeakFlow English para estudante nível básico/intermediário (B1).
- Visual premium, limpo e moderno com paleta em tons suaves de azul.
- Totalmente responsivo (desktop, tablet e mobile).

2. Navegação & Módulos (Menu lateral):
- Conversação: chat com professor virtual carismático e paciente, seletor de tópicos da vida real (viagens, trabalho, restaurantes, compras, entrevistas e cotidiano) ou conversa livre.
- Minhas Frases: banco de frases salvas com busca, filtros por tema/categoria, tradução/explicação e opção de adicionar, editar ou excluir manualmente.
- Histórico: listagem de conversas anteriores organizadas por data e tema.
- Progresso: painel com métricas reais (número de conversas, total de frases aprendidas, tópicos praticados e pontos de atenção).

3. Sistema de Correção no Chat:
- Quando houver erro, exibir bloco de correção estruturado:
  • O que você escreveu
  • Correção
  • Forma mais natural (se aplicável)
  • Explicação curta em português
  • Prática (pergunta curta para fixação)
- Botão rápido para favoritar/salvar frase direto para "Minhas Frases".
- Interface com suporte a áudio/gravação de voz para prática de pronúncia com estados claros.
